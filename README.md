# Paper Implementations

Minimal, from-scratch implementations of recent research papers (AI/ML, systems, algorithms) — one per day. Each folder has a README explaining the paper, what was implemented vs. simplified, how to run it, and real results, plus a demo script and tests. Everything runs on CPU.
